# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone who participates in the project's issues, pull requests, discussions and other spaces is expected to follow it.

## Summary

- Be respectful and considerate toward everyone, regardless of background or experience.
- Give and accept constructive feedback gracefully, and focus on what is best for the project and its community.
- Harassment, insults, personal or political attacks, publishing others' private information, and sexualised language or imagery are not acceptable.

The full text linked above is the authoritative version.

## Reporting

Report unacceptable behaviour privately to the project maintainer, [zuppdev](https://github.com/zuppdev), by using GitHub's **Report content** option on the comment, issue or pull request concerned, or by opening a private security advisory if the matter cannot be raised publicly. All reports will be reviewed promptly and handled confidentially.

## Enforcement

The maintainer may remove, edit or reject comments, commits, code, issues and other contributions that do not follow this code of conduct, and may temporarily or permanently ban contributors whose behaviour is harmful, following the enforcement guidelines of the Contributor Covenant.
